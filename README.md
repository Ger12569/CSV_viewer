# CSV / Excel Web Viewer (Flask)

## Описание проекта

Простое веб-приложение на Flask для загрузки, просмотра и базовой фильтрации CSV и Excel файлов.

Проект позволяет:
- загружать CSV / XLSX файлы
- отображать данные в виде таблицы в браузере
- выполнять простую фильтрацию по колонке
- (опционально) строить график на основе числовых данных

---

## Используемые технологии

- Python 3
- Flask
- pandas
- matplotlib
- openpyxl
- HTML / CSS (простая верстка)
