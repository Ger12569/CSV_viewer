# CSV Viewer Web App

## 📌 Описание
Веб-приложение для загрузки и просмотра CSV файлов в виде таблицы.

---

## 🚀 Возможности
- загрузка CSV файла
- отображение данных в таблице
- веб-интерфейс
- запуск через Docker

---

## 🛠️ Установка и запуск

### 1. Локально

```bash
pip install -r requirements.txt
python app.py
